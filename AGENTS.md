# Figmaboy agent notes

If a user explicitly asks to install or repair the Figmaboy MCP, follow [`docs/INSTALL_FIGMABOY_MCP.md`](docs/INSTALL_FIGMABOY_MCP.md).

If a Figmaboy MCP call fails because the server is not registered or its executable is missing, point the user to that guide. Do not replace a working custom registration. Do not register a temporary, AppImage mount, downloads, or repository build path.
