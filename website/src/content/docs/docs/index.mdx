Figmaboy is a local design editor. You can draw native layers yourself or ask Codex to inspect and edit the open design.

## Make your first design

1. [Download and install Figmaboy](../download/).
2. Create a design or open an existing one.
3. Select **Codex** in the right sidebar.
4. Describe the screen or change you want.

The built-in Codex chat already includes Figmaboy's design tools. You do not need to register an MCP server or run setup commands before your first request.

## What stays local

Designs, previews, chats, and autosave data stay on your machine. Figmaboy stores its own chat history and uses ephemeral Codex runtime threads, so those conversations do not appear in the main Codex history. The built-in sidebar supplies the bundled Figmaboy tools only to its app-server process.

Read [Local data and autosave](./core-concepts/local-data/) for paths and storage behavior.
