## Let Codex handle setup

The built-in chat needs no MCP registration. To use Figmaboy from other Codex clients, paste one prompt and let Codex find, verify, and register the right executable for your operating system.

```text
Open https://raw.githubusercontent.com/0xmiki/figmaboy/main/docs/INSTALL_FIGMABOY_MCP.md and follow it to install or repair the Figmaboy MCP for this computer. Verify the checksum before running a downloaded binary. Keep any working custom registration.
```

[Read what Codex will do](./getting-started/connect-codex/)

No terminal work is required for the normal path. Manual commands remain available when you need them.

## Work by hand or with Codex

Use the canvas directly for frames, type, shapes, images, effects, and precise inspector edits. Open the Codex sidebar with <kbd>Ctrl</kbd> + <kbd>`</kbd> when you want Codex to inspect or change the current design through the bundled Figmaboy MCP server.

## Build your first screen

1. [Install Figmaboy](./getting-started/install/) for your operating system.
2. [Let Codex connect the MCP](./getting-started/connect-codex/) if you want Figmaboy tools outside the built-in chat.
3. Create or open a design in Figmaboy.
4. Open the Codex sidebar with <kbd>Ctrl</kbd> + <kbd>`</kbd> and describe the screen you want.
5. Ask Codex to review the finished frame, then refine it by hand or with another instruction.
